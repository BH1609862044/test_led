## 演示流程

### 第一步：上电自检

- [ ] 按下复位键
- [ ] OLED 显示启动页（项目名 + 版本）
- [ ] LED 闪烁 3 次
- [ ] 串口输出启动信息和版本号
- [ ] 约 1 秒后进入主界面

### 第二步：OLED 主界面

- [ ] 显示 "STM32 CONTROL" 标题
- [ ] 显示 "MODE: MANUAL" 或 "MODE: BLINK"
- [ ] 显示 "LED: ON" 或 "LED: OFF"
- [ ] 显示 "COUNT: 0000" 按键计数
- [ ] 显示 "TIME: xxxs" 运行时间
- [ ] 显示稳定，无明显闪烁

### 第三步：按键控制

- [ ] 按 KEY1：模式在 MANUAL / BLINK 之间切换，OLED 同步更新
- [ ] 手动模式下按 KEY2：LED 翻转，OLED 同步更新
- [ ] 手动模式下按 KEY3：LED 翻转
- [ ] 闪烁模式下按 KEY3：闪烁周期变化（+100ms）
- [ ] 一次按键只触发一次，不会连触发（消抖有效）
- [ ] COUNT 数值与按键次数一致

### 第四步：LED 闪烁模式

- [ ] 切换到闪烁模式，LED 周期性亮灭
- [ ] OLED 显示 "MODE: BLINK"
- [ ] 闪烁周期稳定

### 第五步：串口命令

依次发送以下命令，确认现象：

| 序号 | 命令 | 预期现象 | 结果 |
| --- | --- | --- | --- |
| 1 | `HELP` | 串口返回命令列表，OLED 不变 | ☐ |
| 2 | `LED ON` | LED 亮起，OLED 显示 LED: ON，返回 OK LED=ON | ☐ |
| 3 | `LED OFF` | LED 熄灭，OLED 显示 LED: OFF，返回 OK LED=OFF | ☐ |
| 4 | `LED TOGGLE` | LED 翻转，返回对应状态 | ☐ |
| 5 | `STATUS` | 返回 MODE=xx LED=xx COUNT=xxxx，与 OLED 一致 | ☐ |

### 第六步：错误命令

- [ ] 发送 `LED ABC` → 返回 `ERROR: BAD LED STATE`，LED 不变
- [ ] 发送 `XXX` → 返回 `ERROR: UNKNOWN COMMAND`，状态不变
- [ ] 发送超长字符串 → 系统不崩溃，返回错误
- [ ] 发送空行 → 返回 `ERROR: EMPTY COMMAND` 或静默忽略

### 第七步：快速连发

- [ ] 连续快速发送 10 条 `LED TOGGLE` → LED 状态最终正确，系统不崩溃
