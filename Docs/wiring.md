# 接线图与引脚表

## 整体接线示意图

```
         ┌───────────────┐
         │   DAPLink     │  (下载调试用)
         └───┬───┬───┬───┘
             │   │   │   └── 3.3V ──┐
             │   │   └────── GND ────┤
             │   └────────── SWCLK ──┤
             └────────────── SWDIO ──┤
                                    │
         ┌───────────────┐          │
         │ STM32F103C8T6 │◄─────────┘
         │   (Blue Pill) │
         └───┬───┬───┬───┘
             │   │   └────── PC13 ──► 板载 LED (低电平点亮)
             │   └────────── PA9  ──► CH340 RXD
             │   ┌────────── PA10 ◄── CH340 TXD
             │   │
         ┌───┴───┴───┐
         │   CH340    │  (串口通信用)
         └────────────┘

         I2C 接口 OLED:
         STM32 I2C1_SCL ──► OLED SCL
         STM32 I2C1_SDA ──► OLED SDA
         3.3V ─────────────► OLED VCC
         GND ──────────────► OLED GND

         按键 (上拉输入，按下低电平):
         KEY1 ── PA3 ── GND (按键一端)
         KEY2 ── PA4 ── GND
         KEY3 ── PA5 ── GND
```

## 详细引脚表

### 1. DAPLink / SWD 接口

| DAPLink 引脚 | STM32 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| SWDIO | PA13 | 双向 | SWD 数据 |
| SWCLK | PA14 | → | SWD 时钟 |
| GND | GND | — | 共地，必须接 |
| 3.3V | 3.3V | → | 供电（可选，可用 USB 供电代替） |
| RESET | NRST | → | 复位（可选） |

> ⚠️ PA13、PA14 是 SWD 专用引脚，**不能改作普通 GPIO**。

### 2. USART1 串口

| CH340 引脚 | STM32 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| TXD | PA10 (USART1_RX) | → | CH340 发 → STM32 收 |
| RXD | PA9 (USART1_TX) | ← | STM32 发 → CH340 收 |
| GND | GND | — | 共地，必须接 |
| 3.3V | — | — | 不建议接，避免和 DAPLink 同时供电 |

> ⚠️ TX 和 RX 必须交叉连接！

### 3. OLED I2C 接口

| OLED 引脚 | STM32 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| VCC | 3.3V | → | 电源 |
| GND | GND | — | 地 |
| SCL | I2C1_SCL (PB6) | → | I2C 时钟 |
| SDA | I2C1_SDA (PB7) | 双向 | I2C 数据 |

> OLED 设备地址常见为 `0x3C`，8 位写地址为 `0x78`。
> 如使用其他 I2C 接口，请在 CubeMX 中对应配置并修改 `device_oled.h` 的 I2C 句柄。

### 4. 板载 LED

| 名称 | STM32 引脚 | 有效电平 | 说明 |
| --- | --- | --- | --- |
| 板载 LED | PC13 | 低电平点亮 | Blue Pill 标配 |

### 5. 独立按键

| 按键 | STM32 引脚 | 配置 | 按下电平 |
| --- | --- | --- | --- |
| KEY1 | PA3 | 上拉输入 | 低 |
| KEY2 | PA4 | 上拉输入 | 低 |
| KEY3 | PA5 | 上拉输入 | 低 |

> 按键一端接 GPIO，另一端接 GND。STM32 内部上拉，按下时 GPIO 被拉低。
> 如使用下拉输入（按键接 VCC），需修改 `bsp_key.c` 中的电平判断。

## 安全注意事项

1. **所有模块必须共地**（DAPLink、CH340、OLED、STM32），否则通信异常
2. **禁止向 STM32 GPIO 输入 5V**，必须使用 3.3V 电平
3. DAPLink 和 CH340 不要同时供电，选择一个电源即可
4. 接线前请断开电源，避免短路
5. 首次上电前用万用表检查 3.3V 和 GND 是否短路
